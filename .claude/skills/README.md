# Habilidades del proyecto

Copiadas de [ComposioHQ/awesome-claude-skills](https://github.com/ComposioHQ/awesome-claude-skills) (commit be2a406, 2026-10-25), revisadas antes de agregarlas: solo instrucciones (`SKILL.md`), sin scripts.

- `content-research-writer` — ganchos, guiones y textos con investigación.
- `competitive-ads-extractor` — analiza anuncios de la competencia en bibliotecas de anuncios.
- `twitter-algorithm-optimizer` — optimiza textos cortos para alcance (útil para el copy de las publicaciones).

El resto de la lista (más de 800 automatizaciones de Composio) no se incluye: requieren una cuenta de Composio y no aplican al proyecto.
