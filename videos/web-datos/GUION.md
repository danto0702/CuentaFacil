# Pascal Web · «Tu página web tiene 0,05 segundos» (≈ 83 s, vertical)

Mismo formato que `firma-garabato` y `pdf-datos`: información general con gancho fuerte, promesa de retención («el dato 5 es el que más clientes le hace perder a un negocio») y Pascal Web solo al final, con capturas reales del sitio de ejemplo La Niebla. Voz del dueño clonada con Fish Audio (consentimiento dado), acelerada 8 %.
